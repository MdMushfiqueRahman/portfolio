Hybrid Quantum-Classical UAV Route Optimization

Quantum Hackathon Project

Python · Qiskit · Qiskit Aer · QUBO · QAOA · ArduPilot SITL · MAVLink

Implemented a classical optimization solver and formulated the routing problem as QUBO for QAOA experiments using Qiskit Aer. Evaluated QAOA performance using 1,024-shot simulations at circuit depths p=1 and p=2, comparing solution feasibility against classical optimization results.
